# my-dream-app

Learning website about electricity, grids and small modular reactors (SMRs) for ages 8-18 and early-career engineers.

- [PLAN.md](PLAN.md): vision, workflow and milestone index
- [milestones/](milestones/): one checklist per milestone
- [mockups/](mockups/): static HTML mockups (open `mockups/index.html` in a browser)
- [demo/](demo/): the real codebase, grown one approved milestone at a time

Workflow: every milestone is built on its own `milestone/NN-slug` branch, starts with an HTML mockup, and is only merged into `main` after the owner approves the mockup, then the implementation.
